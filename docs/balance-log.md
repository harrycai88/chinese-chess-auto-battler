# 调参账本

记录每次影响胜负的改动：动机、旧值 → 新值、预期、实测。  
实测使用无头仿真，命令：

```bash
pnpm sim --matches 20 --seed 31 --red charge --black counter
pnpm sim --matches 20 --seed 31 --red counter --black charge
```

## 2026-11-12 · 初版基线

| 项 | 值 |
|:--|:--|
| 基地耐久 | 5600 |
| 攻城倍率 | 1.6 |
| 加时流血 | 96 /s |
| 复活读条 | 兵 12s / 马 16s / 车 17s / 炮 18s |
| 治疗 | 脱战 4s 后 52/s |

**观察**：20 局全部以加时流血结束；双方攻城伤害合计不到 1000，基地血条几乎不动；对局像中场绞肉，缺少“打到基地”的段落。

**判断**：基地太厚、攻城收益太低，且两个策略都缺少主动攻城行为。

## 2026-11-12 · 让基地成为目标

| 项 | 旧值 → 新值 |
|:--|:--|
| 基地耐久 | 5600 → 4200 |
| 攻城倍率 | 1.6 → 1.8 |
| 加时流血 | 96 → 120 /s |
| 复活读条 | 兵 12→13，马 16→17，车 17→18，炮 18→19 |
| 策略 | 全军冲锋在贴近基地时改打基地；防守反击增加突袭位，炮位随阵线推进 |

**预期**：出现真实的攻城段落；对局在加时前后结束，而不是永远拖到流血。

**实测（20 局）**：攻城伤害提升到每方 1.5k–2k；平均 139s；仍以加时流血为主，但基地血量进入 1k 区间，观感明显改善。

## 2026-11-12 · 修复镜像偏差与“种子无效”

**问题**：同策略镜像对打时，一方 10/10 全胜；换种子结果完全一样。原因是：

1. 单位按数组顺序处理，红方永远先手；
2. 引擎内没有任何随机浮动，所有对局是同一场；
3. 完美镜像 + 固定遍历顺序放大了先后手差异。

**改动**：

- 开局按种子洗牌 `turnOrder`，攻击、移动、分离、回血、复活都按该顺序处理。
- 伤害加入可复现的 ±10% 浮动。
- 开局位置加入 ±0.035 格扰动（象除外，保证星位合法）。
- 复活位置加入 ±0.08 格散点（仍会被边界/九宫 clamp）。

**实测（各 40 局）**：

| 对局 | 红胜 | 黑胜 |
|:--|--:|--:|
| 冲锋 vs 冲锋 | 24 | 16 |
| 防守 vs 防守 | 18 | 22 |

同种子结果仍完全一致；不同种子开始跑出不同战况。

## 2026-11-12 · 基地耐久收敛到 3000

对比 2400 / 2600 / 2800 / 3000 / 3200 / 3400 / 3600 各 20 局：

| 基地耐久 | 加时局数 | 基地告破 | 平均时长 |
|--:|--:|--:|--:|
| 3000 | 17 | 3 | 131.0s |
| 3200 | 18 | 2 | 132.4s |
| 3400 | 18 | 2 | 134.5s |
| 3600 | 20 | 0 | 137.6s |

选 **3000**：基地血条在常规时间内有可见变化，偶尔能在加时前直接打穿；平均 2 分钟出头，适合观战。

**最终对局平衡（120 局，种子 31 / 77 / 5）**：

| 对局 | 冲锋胜 | 防守胜 |
|:--|--:|--:|
| 冲锋（红） vs 防守（黑） | 30 | 30 |
| 防守（红） vs 冲锋（黑） | 29 | 31 |
| 合计 | 59 | 61 |

复杂策略胜率 **50.8%**（120 局，三组种子，双向对调），平均时长约 130s。

目标区间：50%–55%。当前落在区间内；两套策略都能赢，且胜负不由“红方先手”决定。
