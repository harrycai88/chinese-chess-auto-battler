# 调参账本

记录每次影响胜负的改动：动机、旧值 → 新值、预期、实测。  
实测使用无头仿真，命令：

```bash
pnpm sim --matches 20 --seed 31 --red charge --black counter
pnpm sim --matches 20 --seed 31 --red counter --black charge
```

## 2026-11-12 · 初版基线

| 项 | 值 |
|:--|:--|
| 基地耐久 | 5600 |
| 攻城倍率 | 1.6 |
| 加时流血 | 96 /s |
| 复活读条 | 兵 12s / 马 16s / 车 17s / 炮 18s |
| 治疗 | 脱战 4s 后 52/s |

**观察**：20 局全部以加时流血结束；双方攻城伤害合计不到 1000，基地血条几乎不动；对局像中场绞肉，缺少“打到基地”的段落。

**判断**：基地太厚、攻城收益太低，且两个策略都缺少主动攻城行为。

## 2026-11-12 · 让基地成为目标

| 项 | 旧值 → 新值 |
|:--|:--|
| 基地耐久 | 5600 → 4200 |
| 攻城倍率 | 1.6 → 1.8 |
| 加时流血 | 96 → 120 /s |
| 复活读条 | 兵 12→13，马 16→17，车 17→18，炮 18→19 |
| 策略 | 全军冲锋在贴近基地时改打基地；防守反击增加突袭位，炮位随阵线推进 |

**预期**：出现真实的攻城段落；对局在加时前后结束，而不是永远拖到流血。

**实测（20 局）**：攻城伤害提升到每方 1.5k–2k；平均 139s；仍以加时流血为主，但基地血量进入 1k 区间，观感明显改善。

## 2026-11-12 · 修复镜像偏差与“种子无效”

**问题**：同策略镜像对打时，一方 10/10 全胜；换种子结果完全一样。原因是：

1. 单位按数组顺序处理，红方永远先手；
2. 引擎内没有任何随机浮动，所有对局是同一场；
3. 完美镜像 + 固定遍历顺序放大了先后手差异。

**改动**：

- 开局按种子洗牌 `turnOrder`，攻击、移动、分离、回血、复活都按该顺序处理。
- 伤害加入可复现的 ±10% 浮动。
- 开局位置加入 ±0.035 格扰动（象除外，保证星位合法）。
- 复活位置加入 ±0.08 格散点（仍会被边界/九宫 clamp）。

**实测（各 40 局）**：

| 对局 | 红胜 | 黑胜 |
|:--|--:|--:|
| 冲锋 vs 冲锋 | 24 | 16 |
| 防守 vs 防守 | 18 | 22 |

同种子结果仍完全一致；不同种子开始跑出不同战况。

## 2026-11-12 · 基地耐久收敛到 3000

对比 2400 / 2600 / 2800 / 3000 / 3200 / 3400 / 3600 各 20 局：

| 基地耐久 | 加时局数 | 基地告破 | 平均时长 |
|--:|--:|--:|--:|
| 3000 | 17 | 3 | 131.0s |
| 3200 | 18 | 2 | 132.4s |
| 3400 | 18 | 2 | 134.5s |
| 3600 | 20 | 0 | 137.6s |

选 **3000**：基地血条在常规时间内有可见变化，偶尔能在加时前直接打穿；平均 2 分钟出头，适合观战。

**最终对局平衡（120 局，种子 31 / 77 / 5）**：

| 对局 | 冲锋胜 | 防守胜 |
|:--|--:|--:|
| 冲锋（红） vs 防守（黑） | 31 | 29 |
| 防守（红） vs 冲锋（黑） | 31 | 29 |
| 合计 | 62 | 58 |

复杂策略胜率 **48.3%**（120 局，三组种子，双向对调），平均时长约 130s。

目标区间：45%–55%。当前约五五开，两套策略都能赢，且胜负不由“红方先手”决定；数值与机制微调留待后续。


## 2026-11-13 · 士的巡防、炮的短射程、精英长复活

**动机**：让护卫的「在不在」变得可感知——士不能站桩、士象阵亡代价极高；炮不再能站在炮塔射程外安全吊射。

### 机制

| 机制 | 旧 | 新 |
|:--|:--|:--|
| 士的活动范围 | 刚性锁在九宫矩形内 | 以基地为圆心的防区圆（半径 2.35），圈内自由走位 |
| 士的移动 | 站定对轰 | 不允许站桩：无指令时沿防区前沿两点往返巡走，接敌后打一轮就换位 |
| 炮的射程 | 4.5 格（可在炮塔外安全攻城） | 3.35 格：压到对面半场才能打基地，且该站位必然在炮塔射程内 |
| 炮的形态切换 | 架起 1.0s / 收起 1.3s | 架起 0.6s / 收起 0.9s（仍有代价，但不再拖节奏） |
| 士、象的复活 | 常规局永久离场，加时白送归队 | 读条 45s / 60s，走完才归队；加时按 0.3 倍率缩短 |
| 出生点 | 只有极淡的虚线圈 | 虚线圈 + 复活符，阵亡时圈内显示倒计时 |

`validateConfig` 新增几何契约：`units.cannon.range + base.radius ≤ base.turret.range + cannon.radius`，否则拒绝配置并指向 `units.cannon.range`。

### 调参过程（关键节点）

| 版本 | 防守反击胜率 | 说明 |
|:--|--:|:--|
| 炮 88 伤害 + 士伤害 38 | 69.4% | 射程砍短但补偿过猛：炮的伤害占比冲到 34% |
| 炮 76 伤害 | 60.9% | 仍是防守方更会用炮 |

| 炮 70 + 炮复活 14s | 51.6% | 关键杠杆：冲锋方的炮死得多，短读条把攻城压力还给了进攻方 |
| 最终（士 38 + 防区 2.35） | 50.0% / 51.2% | 两组独立种子各 400 局，双向对调 |

### 实测（400 局 × 2 组种子，双向对调）

| 指标 | 结果 |
|:--|:--|
| 防守反击胜率 | 50.0%（种子 31/77/5/2026）· 51.2%（种子 7/13/99/4242） |
| 平均时长 | 约 136s（加时平均 14s） |
| 攻城打穿率 | 约 7%（其余以加时流血结束） |
| 伤害占比 | 炮 32% / 车 24% / 马 15% / 兵 13% / 士 9% / 象 7% |
| 镜像对局 | 冲锋 43/57、防守 47/53（先手偏差在种子噪声内） |

**结论**：保留。士从 3.7% 伤害占比升到 9%——它终于是个会动的护卫，而不是一根桩子；炮的伤害占比没有因为射程砍短而下降（31.7% → 32%），因为短射程逼它进入战场中心、命中率反而更高。
